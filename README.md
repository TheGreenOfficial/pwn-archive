pwn learning journy notes/writeups..

*Pwn challenges involve:* <br>
Buffer overflows → overwrite stack data / return addresses <br>
Stack smashing → control RIP/EIP <br>
Format string bugs → read/write arbitrary memory <br>
ROP (Return-Oriented Programming) → chain existing instructions <br>
Heap exploitation → corrupt malloc/free metadata <br>
GOT/PLT exploitation → redirect function calls <br>
Shellcode → execute your own machine code <br>
ret2libc → use libc functions to get a shell <br>
Use-after-free, double-free, tcache attacks, etc. <br>

pwn learning journy notes/writeups..

*Pwn challenges involve:* <br>
Buffer overflows → overwrite stack data / return addresses
Stack smashing → control RIP/EIP
Format string bugs → read/write arbitrary memory
ROP (Return-Oriented Programming) → chain existing instructions
Heap exploitation → corrupt malloc/free metadata
GOT/PLT exploitation → redirect function calls
Shellcode → execute your own machine code
ret2libc → use libc functions to get a shell
Use-after-free, double-free, tcache attacks, etc.
